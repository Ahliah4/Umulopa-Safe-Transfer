# 🩸 Umulopa Safe Transfer

### Blood bank management, made simpler.

Umulopa Safe Transfer is a web application designed to help blood banks manage **blood inventory, requests, transfers, and users** from one central platform.

The project is being developed to make blood management more organised, traceable, and easier to handle digitally.

---

## ✨ What Umulopa Does

* 🩸 Manage blood stock and availability
* 📋 Create and manage blood requests
* 🔄 Track blood transfers
* 👥 Manage users and access
* 📊 View important activity from the dashboard
* 🔐 Keep different parts of the system protected by user roles

---

## 🚀 Run Locally

Clone the project:

```bash
git clone https://github.com/Ahliah4/Umulopa-Safe-Transfer.git
```

Go into the project:

```bash
cd Umulopa-Safe-Transfer
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```

---

## 🔐 Environment Setup

Create a `.env` file in the project root and add the required environment variables.

Example:

```env
VITE_API_URL=http://localhost:5000
```

Keep your actual credentials and secrets out of GitHub.
